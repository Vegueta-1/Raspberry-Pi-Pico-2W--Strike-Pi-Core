Strike Pi Core is an open-hardware controller enhancement platform powered by the Raspberry Pi Pico 2W, delivering advanced features typically found in commercial devices while remaining affordable, customizable, and community-driven.

Features
Rapid Fire
Burst Fire
Anti-Recoil
Smart Adaptive Anti-Recoil
Macro Scripting
Auto Sprint, Drop Shot, Jump Shot, Bunny Hop and others
Profile Management
On-Controller Shortcuts
1000Hz Polling (1ms Response Time)

Supported Hardware
Raspberry Pi Pico 2W
PS4 DualShock 4 (JDM-055 tested)
PS5 DualSense (BDM-010 tested, alpha support don't know if other versions work, I can't not test it because only has that model)

Supported Platforms

Windows, Linux, macOS
Nintendo Switch (Wired Pro Controller Mode)
Android (OTG / USB-C)
PlayStation 3
PlayStation 4 (with user-provided authentication keys)
PlayStation 1 / PlayStation 2 through compatible USB adapters

Strike Pi Core Studio

The included Windows companion application allows users to configure mods, build macros, manage profiles, update firmware, and customize device behavior through a modern graphical interface. All settings are stored directly on the device, allowing fully standalone operation after setup.

Open Hardware

Strike Pi Core is designed for makers, modders, and enthusiasts who want a powerful, transparent, and affordable controller customization platform built on open hardware.

Feedback, testing results, bug reports, and community contributions are welcome.


⚠️ Important Notes

PlayStation authentication files are not provided.
Users must use hardware and keys they legally own.
The project is not affiliated with Sony, PlayStation, Microsoft, Nintendo, Razer, or any hardware manufacturer.
Intended for educational, accessibility, experimentation, and personal controller customization purposes.
